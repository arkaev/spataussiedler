# Детский сад

## Запись

Чаще всего запись через **городской портал**.

## Советы по получению места

1. Написать письмо в каждый сад на районе
2. Описать кто вы
3. Приложить фото ребёнка
4. Написать пару писем в Jugendamt с упором на:
   - Ребёнку нужно учить язык в среде
   - Знакомство с немецкой культурой

При таком подходе довольно быстро можно получить место.
