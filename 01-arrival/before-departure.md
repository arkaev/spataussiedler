# Что успеть перед отъездом

Список носит рекомендационный характер.

## Обязательные дела

1. **Сняться с регистрации** — должно быть сделано ещё на этапе визы, проверяют во Фридланде

2. **Проверить запрет на выезд за границу** — через Госуслуги. Если запрещён — заплатить долги

## Рекомендуемые дела

| Что | Зачем | Примечание |
|-----|-------|------------|
| Сняться с воинского учёта | Военнообязанным | Можно по доверенности (жена/мама), нужен перевод приглашения |
| Закрыть банковский счёт | Справка о закрытии может потребоваться в Jobcenter | Хотя бы один счёт |
| Справка о неполучении пособий | Может потребоваться в Jobcenter | Через Госуслуги |
| Временная регистрация | На всякий случай | |
| Генеральная доверенность | На близкого человека | Всякое может быть |
| Выписки из поликлиники | Для немецких врачей | Особенно при хронических заболеваниях. Перевести |
| Прививочные сертификаты | Для детского сада | Детям обязательна прививка от кори |
| Лекарства на первое время | Если есть необходимость | Купить запас |
